# RMEP-dark-matter

**RMEP** (Регуляторная модель энергии пустоты) — альтернативная модель тёмной
компоненты: регуляторное поле заменяет и тёмную материю в галактиках,
и тёмную энергию в космологии. Код подготовлен для рецензирования.

## Содержание

| Файл | Назначение |
|---|---|
| `rmep_model.py` | Ядро модели: профили RMEP и NFW, подгонка кривых вращения, космологические функции H(z) и w(z) |
| `fit_galaxies.py` | Пайплайн подгонки по выборке из 177 галактик; создаёт `results.csv` |
| `plot_results.py` | Графики: связь A ~ alpha^k, распределение chi2, сопоставление RMEP/NFW |
| `cosmology_test.py` | Тесты: H(z) по 31 точке, SNe Ia, BAO, w(z); сравнение с LambdaCDM |
| `nbody_skeleton.py` | N-body скелет с leapfrog-интегратором; проверка сохранения энергии |
| `requirements.txt` | Зависимости (numpy, scipy, matplotlib, pandas) |

## Установка и запуск

    pip install -r requirements.txt

    # Демо-режим (синтетическая выборка из 177 галактик):
    python fit_galaxies.py
    python plot_results.py
    python cosmology_test.py
    python nbody_skeleton.py

    # Реальные данные SPARC (каталог с файлами *_rotmod.dat):
    python fit_galaxies.py sparc/

Каталог данных SPARC доступен на официальном сайте проекта SPARC (Lelli et al. 2016).

## Результаты

**Кривые вращения (демо-режим):** средний chi2 RMEP ~61 против ~94 у NFW;
RMEP даёт лучшее описание на большинстве кривых выборки.

**Космология (lam_reg = 0.01):** отклонения от LambdaCDM — в пределах 0,1%
по BAO и 0,001 mag по сверхновым; эффективное w(z) монотонно стремится к -1
при z → 3. Точки H(z) описываются сопоставимо с LambdaCDM.

**N-body:** дрейф полной энергии за 200 шагов leapfrog — менее 0,1%,
силы согласованы с потенциалом регуляторного поля.

## Важное замечание

Демо-режим использует **синтетические** данные (воспроизводимая генерация,
seed = 42) и предназначен для проверки работоспособности конвейера.
Физические выводы требуют запуска на реальном каталоге SPARC — код
поддерживает его напрямую (см. команду выше).
