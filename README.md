# РМЭП — Регуляторная модель энергии пустоты

**Регуляторная модель энергии пустоты и её связь с тёмной материей и тёмной энергией.** Эмпирическая проверка на каталоге SPARC (175 галактик). Версия 5.0 — каноническая, согласована с объектным программным кодом. Актуализирована по состоянию на ноябрь 2026 г.
**[English version summary → RMEP_en.md](RMEP_en.md)** — краткая сводка гипотезы на английском языке.
## Аннотация

Предлагается регуляторная модель энергии пустоты (РМЭП) — альтернатива гипотезе тёмной материи на едином механизме: локальные конфигурации вакуумного конденсата с пылевым гравитационным откликом, масштаб и амплитуда которых связаны с барионным состоянием системы. Релятивистская формулировка сохраняет стандартную ОТО: конденсат входит в тензор энергии-импульса как обычная масса, метрика не модифицируется — стандартная гравитация вне зоны регуляции, стандартное линзирование, скорость гравитационных волн равна скорости света.

Эмпирическая проверка выполнена на полной выборке каталога SPARC (175 галактик, 3391 точка данных). При равном числе свободных параметров профиль РМЭП — плотность конденсата с плоским ядром — описывает кривые вращения существенно лучше стандартного NFW-профиля: РМЭП выигрывает в 107 случаях против 31, ничьих 37; медианные χ²_red составляют 23,2 против 36,3. Проблема core–cusp решается без дополнительной физики. Связь масштаба регуляции с барионным состоянием формулируется как рабочее допущение: основной прогон даёт скейлинг α ≈ 5 кпк·(V_max/100 км/с)^1,89 с бутстреп-интервалом показателя [1,34; 2,41], однако независимая проверка не воспроизводит конкретную форму зависимости — её эмпирический статус остаётся открытым. Модель воспроизводит радиальную корреляцию дискрепанса с ускорением (условное воспроизведение RAR) и предсказывает конечную полную массу регуляции с кеплеровским участком кривой вращения у 72 из 175 объектов — различающее предсказание против расходящихся гало. Тест универсальности переходного ускорения выполнен расчётом: медианное переходное ускорение 0,14·a₀ воспроизводит феномен a₀ MOND по порядку величины, а выявленный систематический тренд с массой — новое различающее предсказание.

В космологии модель наследует стандартный фон по построению (согласие с H(z), BAO и CMB); различающая сила переносится в структурные тесты: эволюцию доли регуляции на z ~ 1–2,3, масс-шаг сверхновых Ia, низкие мультиполи CMB через эффект Сакса–Вульфа и исход измерений DESI по w(z) с двумя различающими исходами. В сильном поле модель не вносит наблюдаемых изменений; внутренняя полевая структура компактных объектов — физическая интерпретация, а не количественный результат.

Границы модели очерчены явно: количественно проверена галактическая часть; скопления и линзирование описаны качественно; предсказания ранних версий, не воспроизведённые в текущей формулировке, переведены в архив с записью причин. Сформулирована программа различающих проверок с заранее записанными критериями исхода.

## Воспроизведение расчётов

Код в репозитории:

- `rmep_model.py` — модель регуляции (профиль конденсата);
- `fit_galaxies.py` — подгонка кривых вращения каталога SPARC (сравнение РМЭП против NFW);
- `cosmology_test.py` — космологическая проверка;
- `nbody_skeleton.py`, `rmep_blackhole.py` — скелет N-body и тест сильного поля;
- `plot_results.py` — построение графиков;
- `requirements.txt` — зависимости.

Порядок запуска: установить зависимости (`pip install -r requirements.txt`), затем последовательно выполнить `fit_galaxies.py`, `cosmology_test.py`, `plot_results.py`.
