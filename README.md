# RMEP-dark-matter

DOI: [10.5281/zenodo.24443470](https://doi.org/10.5281/zenodo.24443470) — Zenodo record (preprint, version 5.0).

Гипотеза РМЭП (регуляторная модель энергии пустоты): альтернативный подход к проблеме тёмной материи, в котором недостающий гравитационный вклад галактик объясняется не невидимыми частицами, а релаксирующей конфигурацией вакуумоподобной компоненты, следящей за барионным потенциалом.

## О работе

Модель проверена подгонкой профиля регуляции по полной выборке каталога SPARC (175 галактик, 3391 точка данных). При равном числе свободных параметров профиль РМЭП описывает кривые вращения существенно лучше стандартного NFW-профиля: РМЭП выигрывает в 107 случаях против 31, ничьих 37. Ключевые элементы:

- локальная вакуумная компонента с экспоненциальным профилем ρ_0·exp(−R/α) и плоским ядром;
- масштаб регуляции α, связанный с максимальной скоростью вращения (рабочее допущение α ≈ 5 кпк·(V_max/100 км/с)^1,89; независимая проверка конкретную форму не воспроизводит);
- релятивистская формулировка: стандартная ОТО, конденсат входит в тензор энергии-импульса как обычная масса (раздел 9);
- предсказание кеплеровского падения кривых вращения за масштабом регуляции — у 72 из 175 объектов;
- воспроизведение радиальной корреляции дискрепанса с ускорением (основа RAR, воспроизведение условное);
- переходное ускорение 0,14·a₀ по порядку величины совпадает с a₀ MOND — без постулирования константы;
- в космологии модель наследует стандартный фон по построению (H(z), BAO, CMB); различающая сила — в структурных тестах (z ~ 1–2,3, масс-шаг сверхновых Ia, эффект Сакса–Вульфа, DESI по w(z)).

## Структура репозитория

- `RMEP_5.0_RU.md` — основная работа, русская версия (5.0, ноябрь 2026)
- `RMEP_5.0_EN_final_v2.md` — английская версия
- `fit_galaxies.py` — подгонка кривых вращения SPARC (сравнение РМЭП против NFW)
- `rmep_model.py` — модель регуляции (профиль конденсата)
- `rmep_blackhole.py` — тест сильного поля (раздел 9.3)
- `cosmology_test.py` — космологическая проверка
- `nbody_skeleton.py` — скелет N-body
- `plot_results.py` — построение графиков
- `requirements.txt` — зависимости Python
- `figure_6_8_1.png` — масштаб регуляции α(V_max)
- `figure_9_1.png` — иллюстрация релятивистской формулировки

## Воспроизведение расчётов

1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить подгонку: `python fit_galaxies.py`
3. Построить графики: `python plot_results.py`
